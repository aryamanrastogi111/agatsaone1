# EasyTouch Rhythm Band Shopify Theme v13

This version is a standalone Shopify Online Store 2.0 theme export for EasyTouch Rhythm Band.

## What changed
- Header menu is pre-wired with Home, Shop, Reviews, and FAQ links.
- Black colour is included across the colour showcase and buy box.
- Buy Now/Add to Cart uses Shopify cart and checkout, not any AgatsaOne website logic.
- Reviews are visible as a dedicated editable section. Add only genuine customer reviews from the Theme Editor.
- Activity popup is visible by default as a generic store activity notice, and can show real recent order entries if you add them manually.
- Stock urgency bar is included in the buy box and uses Shopify inventory when available, otherwise a configurable fallback count.
- Homepage and Rhythm page templates both include the reviews and activity popup sections.

## After uploading
1. Go to Online Store > Themes > Customize.
2. Open the Home page.
3. Pick your actual Rhythm Band product in the Rhythm hero and Buy box sections.
4. Make sure the product has colour variants named Olive, Graphite, Khaki, Slate, Rosewood, Teal, and Black if you want all swatches to map directly to variants.
5. Add genuine customer reviews in the Customer reviews section, or leave it empty until you have real reviews.
6. Add real recent order entries in the Activity popup section if you want customer-specific popup activity.
7. Replace images from each section's image picker if needed.
8. Drag, hide, duplicate, or remove sections from the left sidebar.

Bundled fallback images still show even before you upload your own images, but the settings are editable.
